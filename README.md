#  Stellar Flows

Интернет-магазин авторских букетов, концепт космических названий, взятых из списка существующих созвездий. Представляет собой каталог товаров, корзину и возможность оформления заказа. Выполнено с использованием HTML, CSS и JavaScript, без фреймворков.

**Deploy:** 


## Возможности

- Каталог букетов: карточки с фото, названием, ценой и кнопкой «Добавить в корзину»
- Корзина: добавление товара, удаление, изменение количества кнопками «+» и «−»
- Автоматический пересчёт итоговой суммы при любом изменении корзины
- Сохранение корзины в `localStorage`: данные не пропадают после обновления страницы
- Оформление заказа в модальном окне (`<dialog>`): имя, фамилия, адрес доставки, телефон
- Валидация полей формы средствами браузера (`required`, `pattern`)
- Сообщение «Заказ создан!» после отправки формы, корзина при этом очищается
- Адаптивный дизайн: ноутбук, планшет, смартфон

## Технологии

- **HTML5**: семантическая разметка (`header`, `nav`, `main`, `section`, `aside`, `article`, `footer`, `dialog`, `output`)
- **CSS3**: Flexbox, Grid, CSS-переменные, медиазапросы
- **JavaScript (ES6+)**: DOM, делегирование событий, `localStorage`, `JSON`, `Intl.NumberFormat`
- Без CSS- и JS-фреймворков и библиотек

## Локальный запуск магазина

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/linaank/stellar_flows.git
   cd stellar_flows
   ```
2. Запустите `index.html` через Live Server в VS Code, либо откройте в браузере двойным щелчком. 

Сборка и установка зависимостей не требуются.

## Как это работает

- Каталог из массива `products` (`js/products.js`), поэтому новый товар добавляется одной строкой в массив.
- Корзина хранится как массив `{ id, qty }`. Цена и название всегда берутся из каталога, а в `localStorage` (ключ `stellar-flows-cart`) сохраняются только `id` и количество.
- Любое изменение корзины проходит через функцию `update()`: она сохраняет данные в `localStorage` и перерисовывает корзину.
- При загрузке данные из `localStorage` проверяются: несуществующие товары и некорректное количество отбрасываются.

## Адаптивность

| Ширина экрана | Раскладка |
|---|---|
| от 1025 px (ноутбук) | каталог и корзина в две колонки, корзина закреплена при прокрутке |
| до 1024 px (планшет) | корзина располагается под каталогом |
| до 600 px (смартфон) | карточки в две колонки, уменьшенные отступы |
| до 380 px | карточки в одну колонку |
